# APRENDA FÁCIL — PMPE 2027

Aplicativo estático para GitHub Pages. Não exige cadastro nem servidor; o progresso fica salvo no navegador/dispositivo (localStorage).

## Banco de questões
- 6.000 exercícios incluídos: 1.000 por matéria.
- Cinco alternativas (A–E), gabarito e explicação após responder.
- Questões autorais para treino no estilo de cobrança AOCP.
- Não são 6.000 questões oficiais nem 6.000 itens independentes de provas anteriores: o banco aplica diferentes contextos aos conceitos-base disponíveis. Questões anteriores só devem ser identificadas como tais quando importadas com fonte verificável.

## Matérias
1. Língua Portuguesa
2. História de Pernambuco
3. Raciocínio Lógico
4. Informática
5. Direito Constitucional
6. Direitos Humanos e Legislação Extravagante

## Publicar no GitHub Pages
1. Extraia o ZIP.
2. Envie os arquivos de `pmpe-study` para a raiz do repositório.
3. Em Settings → Pages, selecione Deploy from a branch, `main` e `/(root)`.

O progresso é local ao navegador. Para não perder dados, use a exportação/importação de backup disponível no app.
